## 配布資料・ツールの説明
- `手順書/Webかるた_用語リスト.pptx` / `.pdf`：学生に配る用語リスト（出題対象のみ。ダミー札は載せない）。
- `tools/make_term_list.py`：`public/karuta-data.js` から用語リストの PPTX を作る（`pip install python-pptx` が必要）。
- `tools/pptx_to_pdf.ps1`：PowerPoint で PPTX を PDF に書き出す。
- `mockups/`：実装前の画面案（`survey-mockup.html` はプレイ後アンケートの案）。
- `survey.js` / `public/survey.js`：プレイ後アンケート（サーバー側の受付とCSV保存 / 参加者の画面）。
